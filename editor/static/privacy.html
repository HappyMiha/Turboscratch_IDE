TurboScratch IDE Privacy

TurboScratch IDE is a modified version of TurboWarp and Scratch. This page describes what this copy of the editor does with your data.

Projects on your computer

Projects you open or save from your computer stay on your computer. Editor settings, your collaboration name and the last collaboration server you used are kept in your browser's local storage.

Collaboration rooms

When you join a room, your name, your project (including its images and sounds), your edits and your chat messages are sent to the collaboration server you chose, and to everyone else in that room. The server keeps a copy of each room's project in its data folder so the room survives a restart. Whoever runs that server can see this data. Anyone who knows a room code can join that room, so only share codes with people you trust.

Services run by others

Some features still use online services that this project does not run, which have their own policies: loading projects from scratch.mit.edu, the sprite/costume/sound libraries, TurboWarp's cloud variable server, and the TurboWarp extension gallery. If you don't use those features, they aren't contacted.
